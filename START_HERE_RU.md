# Dark Fantasy Backpack — v3

## Что готово
- Новые живописные изображения десяти семейств предметов. Для рюкзака оружие дополнительно вырезано и ориентировано вертикально; магазин показывает исходные иллюстрации. Уровни T1–T5 различаются рамкой и меткой, а не пятью уникальными рисунками каждого предмета.
- Шесть новых живописных портретов героев вместо мультяшных значков.
- Новый интерфейс: графит, сталь, потёртая латунь; читаемые карточки, подсказки, клавиатура и сенсорные действия.
- Тренировка с ботами и 2.5D-анимация работают в `public/index.html` без интернета.
- Реализован клиент приватных комнат на 2–4 и серверный Firebase Functions расчёт общего боя, готовность/фиксация сборок, повтор по событиям, переход раундов и восстановление комнаты. Код нацелен на существующий Firebase-проект `dnd-gay`.

## Что пока не активировано
В Firebase ничего не опубликовано и реальные серверные вызовы не проверялись. Конфигурация web app не даёт административного доступа для публикации Functions, Hosting или Rules. Проверь настройки Anonymous Authentication и наличие тарифа Blaze; сам тариф не меняется.

Anonymous: Firebase Console → Security / Authentication → Sign-in method → Anonymous → Enable.
Бои вычисляет сервер, но покупки/владение вещами пока sandbox: без рейтинга и утверждения о защите экономики от читов. Игрок может менять локальную сборку до готовности. Между серверными раундами одинаковый sandbox доход +8, повторный снимок не выдаёт награду дважды.

## Запуск прямо сейчас
Открой `public/index.html` в современном браузере. Введи имя, выбери героя, начни тренировку, собери рюкзак, нажми «Тренировка с ботом». Локальный file:// не подходит для приглашения друзей — нужна опубликованная HTTPS-версия.

## Публикация — только после подтверждения настроек
На компьютере с доступом владельца и Node.js22:

```bash
npm install -g firebase-tools
firebase login
cd functions
npm install
cd ..
npm --prefix functions test
firebase deploy --only functions:backpack-v3 --project dnd-gay
firebase hosting:channel:deploy backpack-v3 --expires 7d --project dnd-gay
```

Сначала используй preview-канал, а не замену текущего live сайта. Его ссылку выводит CLI; она действует 7 дней. Канал не изолирует backend/базу автоматически: Functions используют тот же Firebase-проект, в новом namespace `backpack_v3`.

### Правила базы — обязательный отдельный аудит
В firebase.json намеренно НЕТ секции database. Фрагмент `database.rules.namespace-fragment.json` нельзя просто вставлять поверх неизвестных существующих Rules и считать безопасным: разрешение чтения/записи у корня или любого предка наследуется и не может быть отменено запретом ниже. Сначала выгрузи и проверь действующие Rules, сохрани резервную копию и согласуй необходимые изменения, не ломая текущую игру. Deny-default template из технического пакета относится только к новому тестовому проекту/эмулятору, не к твоей действующей базе.

## Проверки и ограничения
Локальные тесты интерфейса и нескольких независимых браузерных клиентов находятся в QA-документах. Сетевой тест использовал локальный mock adapter с тем же движком, а НЕ Firebase emulator/production. Backend и правила нужно проверить в Firebase Emulator Suite, затем выполнить настоящий тест 2–4 клиентов после публикации. Никаких существующих данных и правил в проекте не менялось.
