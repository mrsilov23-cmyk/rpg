# Backpack Brawl · новый Firebase backpuck-ef94b

## Обновлено
Конфигурация HTML, отдельного клиентского кода, .firebaserc и команд публикации нацелена только на backpuck-ef94b. Старый dnd-gay и «Бункер» не используются и не изменены. Сохранения комнаты/тренировки/кошелька отделены новыми ключами localStorage; Firebase app name также включает новый projectId.

Используются Firebase App + Anonymous Authentication + Realtime Database. Anonymous Auth в новом проекте владелец подтвердил включённым. Analytics не инициализируется: measurementId сохранён в конфигурации, но для игрового подключения сбор аналитики не нужен. Предметы/портреты/2.5D-арена встроены в HTML и не требуют Cloud Storage.

## Порядок настройки
1. В Firebase Console выбери **backpuck-ef94b**, а не старый проект.
2. Realtime Database → Rules: сохрани текущую копию, проверь **database.rules.json** в компиляторе/симуляторе или Emulator Suite, затем замени Rules целиком содержимым этого файла и опубликуй после успешной проверки.
3. Правила закрывают корень; единственная игровая ветка — backpack_spark_v4. Веток/разрешений «Бункера» в этом файле нет. Не вставляй фрагмент под публичным root allow.
4. После публикации/проверки Rules загрузи **public/index.html** на HTTPS-хостинг. Это готовая онлайн-версия: флаг подтверждения Rules уже выставлен, поэтому НЕ используй её для онлайн-комнат до шага2. Тренировка в локальном HTML доступна сразу; для сетевой игры file:// не подходит.
5. Для дополнительной безопасной подготовки есть **training-until-rules.html** — сеть заблокирована. Не используй его как окончательную онлайн-версию.
6. Проверь два клиента: создать комнату, приглашение по полной ссылке, готовность, одинаковый результат и следующий раунд; затем 3/4 клиента, отключение и возврат организатора.

## Публикация через Firebase CLI
На своём компьютере с доступом владельца:

```bash
npm install -g firebase-tools
firebase login
firebase use backpuck-ef94b
# После проверки новых Rules, для этого отдельного проекта:
firebase deploy --only database,hosting --project backpuck-ef94b
```

Чтобы сначала проверить сайт без замены live-сайта:

```bash
firebase deploy --only database --project backpuck-ef94b
firebase hosting:channel:deploy backpack-preview --expires 7d --project backpuck-ef94b
```

Ссылку выводит CLI. Preview использует ту же базу, поэтому Rules нужны до теста. Все команды явно указывают новый projectId. Cloud Functions не деплоятся, billing/Blaze не подключается. Квоты Spark действуют.

## Границы доверия и проверки
Бой рассчитывает организатор, остальные проверяют детерминированный результат. Это дружеский sandbox, не защищённый рейтинг; происхождение/экономика вещей не подтверждаются сервером. При отключении организатора новый расчёт ждёт его возврата, автоматического назначения нового ведущего нет.

Никаких remote Firebase reads/writes, публикаций правил или хостинга в рамках переноса не выполнялось. Правила и протокол ранее прошли локальные/статические проверки, но настоящий Firebase Rules compiler/emulator и live-тест нового проекта ещё не выполнены.
