# Итоговая проверка интеграции

- Inline JavaScript финальной сборки проверен на синтаксис.
- 10/10 тестов чистого серверного движка.
- UI: 390/800/1024/1440px, покупка, перемещение, объединение, продажа, клавиатура — PASS; без JS-ошибок, без элементов управления меньше 44px в проверенном игровом экране.
- Итоговый merged HTML проверен несколькими независимыми браузерными клиентами через LOCAL MOCK adapter: лимит четыре, отклонение пятого, готовность, одинаковый результат, reconnect, переход раунда, треугольник троих, отсутствие повторного +8, скорость1x по timestamps, отражение сторон, ошибка CDN и тренировка без сети.
- Это не Firebase Emulator Suite и не реальный сетевой тест. Live правила, Anonymous Auth, тариф и deployment не проверены.
- Новый арт предметов просмотрен в рюкзаке и магазине на desktop/mobile. Портреты героев — новая единая живописная серия.
- Действующая база и hosting не изменялись. Установка Firebase CLI здесь не завершилась из-за отсутствия DNS-доступа к npm registry; публикация из этой среды не выполнена.
